# to-do-list-
To-Do List
About the Project

This is a simple To-Do List application that helps users organize their daily tasks. It allows users to add tasks, keep track of their work, and manage their daily activities in one place.

I created this project to practice my programming skills and learn how to build a useful application with a simple and user-friendly interface.

Features
Add new tasks to the list.
Mark tasks as completed.
Delete tasks when they are no longer needed.
View and manage daily tasks.
Simple and easy-to-use interface.
Technologies Used
HTML
CSS
JavaScript
How to Run
Clone this repository to your computer.
Open the project folder in Visual Studio Code.
Open the index.html file in your browser.
Start adding and managing your tasks.

You can also use the Live Server extension in Visual Studio Code to run the project.

How to Use
Enter a task in the input field.
Click the Add button to add it to your list.
Mark a task as completed when you finish it.
Delete tasks that you no longer need.
What I Learned

While working on this project, I practiced using JavaScript to handle user input, update the page dynamically, and manage tasks. I also gained experience in creating a simple interface using HTML and CSS.
